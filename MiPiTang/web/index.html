v0.30
打烊机制重做 + 界面打磨
  • 打烊机制重做：游戏界面顶部新增营业进度条「第 N 天 · 还剩 mm:ss」，最后 30 秒变红，到点自动打烊不再突然弹出
  • 打烊状态写入存档，离开游戏、返回首页都会先结算当天，不会再出现一进游戏就弹打烊面板
  • 「提前收摊」只保留进度条右侧的一个入口，顶栏不再重复；提前收摊会先确认，并把剩余营业时间的销售额折算入账
  • 打烊面板标题显示「第 N 天 · 打烊啦」，「明天继续」改名为「开始下一天」，两个按钮行为一致
  • 规则页「存档迁移」补齐完整说明（导出 → 复制/存文件/截屏 → 导入 → 覆盖提醒），反馈入口独立放到页面底部
  • 按钮系统：各变体拥有专属按下态，按下去不再闪成同一种暖棕色
  • 按钮禁用态保留底部阴影，禁用/启用切换时不再上下跳动
  • 按钮加渐变和内高光，补充桌面端悬停与键盘聚焦样式
  • 首页菜单按钮按功能分三档配色：开始游戏突出，信息类弱化，迁移/互联换浅紫
  • 窄屏下按钮文字不再溢出容器
  • 规则页流程图节点改为胶囊形，英文「Board / Stock」不再溢出圆形
  • 规则页色条改为书签样式，步骤块改为白底描边，步骤序号加立体感
  • 制作人员名单：主制作卡片高亮，彩蛋名字加呼吸提示和「轻点试试」，点击会有「嗯？」「再点一次…」反馈
  • 制作人员名单页脚新增版本号
  • 模态框和打烊面板改为淡入缩放动画
  • 装饰商店卡片补上间距，更新页「最新」标签补上样式
v0.29
前期节奏优化 + 数值透明 + 等待期交互
  • 开局送 6 金币，第一次升级可在 10~15 秒内完成
  • 熬糖锅初始 3 秒、摊位初始 2 秒一位顾客，前期节奏明显加快
  • 案板 Lv.1 一次擀 2 份，且每升一级至少 +1 份（修复 Lv.2 升级无效的问题）
  • 熬糖锅进度条未满时，点击锅子可以「搅拌」加速熬糖
  • 离线收益上限改为动态，随设备等级和每秒收入提升，不再固定 500 金币
  • 库存为 0 时「每秒收入」显示 0，不再显示理论值
  • 顾客气泡按实际购买量匹配，不再出现「买三份」却只买一份的情况
  • 升级按钮下方显示「当前 → 下一级」数值，升级收益一目了然
