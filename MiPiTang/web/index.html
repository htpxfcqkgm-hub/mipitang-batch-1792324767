更新信息
米皮糖小摊的版本记录
v0.35最新
黑名单 + 设置页打磨
  • 接入只读黑名单：启动拉取一次，本地缓存 24 小时
  • 拉取失败静默使用旧缓存，不影响开局
  • 交易时命中黑名单直接拒绝，优先级高于好友关系
  • 设置页显示黑名单状态：已加载 N 条 · 日期，失败则显示使用本地缓存
  • 新增设置页，分四组：身份、设置、数据、关于；首页的清空存档 / 改昵称移入设置页
  • 设置页也能切换语言，并标出当前语言
  • 清空存档文案改为：昵称保留，但玩家 ID 会重置，通讯录和交易记录将失效
  • 交易码压缩到约 160~200 字符（原来 300+），转发不再被截断；旧交易码仍可识别，粘贴时换行、空格、全角、智能破折号、中文包裹都能容错；自动复制失败会帮你选中文本
v0.34
赠与交易码
  • 新增赠与交易码：按玩家 ID 定向赠与金币，只有指定 ID 能领
  • 交易码经 HMAC-SHA256 签名，覆盖 id / 发送方 / 接收方 / 金币 / 创建与过期时间
  • 领取顺序：验签 → 核对接收方 → 检查有效期 → nonce 去重
  • 金币在生成时扣除，7 天内有效，过期作废
  • 发送方昵称只做展示，不参与签名
  • 签名抽成 TradeCrypto.sign / verify 薄接口，日后接服务端只换内部实现
v0.33
玩家身份 + 通讯录
  • 首次起名时本地生成玩家 ID，格式 MPT-XXXX-XXXX
  • ID 由 crypto 随机 5 字节转 base32，去掉容易混淆的 0 / O / 1 / I
  • 玩家 ID 存入存档，改名不换 ID；老存档读入时自动补 ID
  • 新增通讯录：按玩家 ID 添加联系人
  • 联系人的称呼由本机自己填，不会同步对方真名
  • 通讯录支持添加 / 改名 / 删除，全部存在存档里
v0.32
iPhone 互联互通修复 + 金币自动到账
  • 修复 iPhone 上互联互通读不到其他游戏数据的问题（每个文件存档互相隔离）
  • 新增「其他游戏」入口，蛋仔 / 氧气 / 酱味装进本文件，共用这一份存档
  • 新增一次性互通码：生成即扣下，导入时按编号去重；蛋仔 / 氧气 / 酱味只负责生成，兑换全部在这里完成
  • 同源时数据改动实时同步，互联互通弹窗自动刷新
  • 首页直接显示蛋仔 / 氧气 / 酱味的数据，不用点进弹窗
  • 「存档迁移」导出时把其他游戏的数据一起装进密文，换设备一次带走
  • 自动领取蛋仔 / 氧气 / 酱味兑换后写入的金币，不用再手动确认
  • 酱味大鸡兑换改为按「总分 − 已兑换」计算，不会和本作重复领金币
  • 各游戏更新日志补全，互通弹窗新增滚动，小屏不再被截断
v0.31
加急卖打折 + 收益显示修复
